# Dict с интересными фишками языка Си

  

Данный проект является тренировочным и не всегда содержит логичные или оптимальные решения.

Побочная задача это создание словаря с ключом `char*` и данными `void*`. Основная это использование в разработке и описание в README интересных вещей, найденных во время чтения книг и статей.

Строится словарь из 4х основных сущностей, состоящих из структур и функций, ими управляющими: `List`, `KeyVal`, `ListKeyVal`, `Dict`.

Каждая из сущностей покрыта тестами и имеет свои фишки реализации. В основе реализации лежит хэш таблица. (возможно вместо листа я буду использовать какое-нибудь дерево, но это пока только планы)

  

# List

Эта сущность является двусвязным списком, каждый элемент которого хранит только ссылки на соседей. Сущность не управляет памятью и только обращается с отдельными `ListNode`.

### Интересное

В основном это довольно банальная сущность. Она намеренно сделана без усложнений, чтобы быть строительным материалом для более крупных структур данных.
